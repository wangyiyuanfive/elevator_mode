# elevator\_mode — 基于 Modbus TCP 与模糊逻辑的电梯运行模式识别系统

> 西门子杯（中国智能制造挑战赛）电梯系统赛项・Python 实现

## 项目简介

本项目通过 **Modbus TCP** 协议与西门子 S7-1200 PLC 实时通信，采集电梯控制系统的 IO 信号，并利用**模糊逻辑**对电梯客流进行在线识别，输出电梯当前的运行模式（极端闲时 / 早高峰 / 晚高峰 / 午间双向交叉峰 / 层间交互客流 / 会议活动突发流），为电梯群的智能调度提供决策依据。

## 功能特性



* **PLC 实时通信**：基于 pymodbus 封装 Modbus TCP 客户端，支持保持寄存器读写、浮点数 / 32 位整数转换

* **128 位布尔流解析**：将 8 个 VALUE 寄存器（共 128 位）按位映射为 118 个有效电梯信号点位（呼梯、轿内选层、门锁、平层、限位、检修、光幕等），并自动过滤 10 个备用点位

* **滑动窗口特征提取**：基于 600 帧时序缓存（deque），提取呼梯强度、上下行呼梯占比、楼层集中度等客流特征

* **模糊逻辑推理**：三角形隶属度函数 → 6 条模糊规则 → 最大隶属度解模糊，在线判断 6 种电梯运行模式

* **数据落盘**：采集数据实时写入 CSV（utf-8-sig，Excel 可直接打开），便于离线分析与复盘

## 技术栈



* Python 3

* pymodbus（>= 3.0.0）

* 模糊控制理论（隶属度函数 / 规则库 / 解模糊）

## 项目结构



| 文件                  | 说明                                   |
| ------------------- | ------------------------------------ |
| `config.py`         | PLC IP / 端口 / 寄存器地址与数据类型映射 / 采样间隔配置  |
| `modbus_client.py`  | Modbus TCP 客户端封装（连接、读写、数据类型转换、上下文管理） |
| `data_converter.py` | 寄存器与 float /int 数据类型转换（IEEE 754 大端序） |
| `main.py`           | 主程序：数据采集、128 位解析、特征提取、模糊推理、CSV 记录    |
| `main_1.py`         | 针对特定 EET 版本数据块的程序变体                  |

## 6 种电梯运行模式



| 模式      | 特征          |
| ------- | ----------- |
| 极端闲时    | 几乎无呼梯       |
| 早高峰     | 上行客流为主      |
| 晚高峰     | 下行客流为主      |
| 午间双向交叉峰 | 上下行客流都大     |
| 层间交互客流  | 各楼层均衡交互     |
| 会议活动突发流 | 短时间内多楼层集中呼梯 |
